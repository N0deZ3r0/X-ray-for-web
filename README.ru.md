Блокировщики говорят вам «заблокировано 47 трекеров». Это число невозможно
проверить, и все, кто его показывает, считают его по-разному. Этот прибор не
показывает счётчиков. Он показывает улики.

**1. Что сайт прочитал.** Журнал обращений к поверхностям отпечатка — холст,
видеокарта, звук, шрифты, экран, устройство — с привязкой к конкретному скрипту
через стек вызова и меткой времени от начала загрузки.

```
0.42 с   canvas.toDataURL              сторонний   https://ads.example/t.js:1:8420
0.42 с   webgl.getParameter  ×3        сторонний   аргумент: UNMASKED_RENDERER_WEBGL
0.51 с   audio.OfflineAudioContext     первая сторона
```

**2. Что ушло наружу.** Перехваченные маячки, разобранные по полям человеческим
языком. Не base64-каша, а:

```
POST https://www.facebook.com/tr        подтверждено сетью
  Идентификатор пикселя            1234567890
  Хеш вашего адреса электронной почты   e3b0c442…
      SHA-256. Расшифровать нельзя, но он одинаков на всех сайтах —
      по нему вас узнают в профиле Facebook
  НЕ ОПОЗНАНО: dpo, fbc_f            показано как есть
```

**3. Что прошло мимо прибора.** Прибор наблюдает из двух независимых источников:
обёртки внутри страницы и сетевой уровень браузера. Запрос, который видела сеть,
но не видели обёртки, — это обход инструментации, и он назван обходом.

## Чего он не делает

- Не блокирует. Ничего. Никогда.
- Не считает «заблокированных трекеров».
- Не показывает биты энтропии и оценку уникальности вашего отпечатка. Их не
  существует без распределения по всем пользователям, а прибор стоит на одной
  машине. Вместо этого — «снято 14 поверхностей отпечатка из 67».
- Не называет поле, назначение которого не установлено. Неопознанное помечено
  «НЕ ОПОЗНАНО» и посчитано.
- Не отправляет никуда ни байта. См. «Как проверить это самому».

## Установка

Расширения нет в магазине — ставится распакованным.

1. Скачайте zip со страницы [Releases](https://github.com/N0deZ3r0/X-ray-for-web/releases/latest)
   и распакуйте. Его собирает CI из того коммита, на который указывает тег, и внутри
   только расширение: без стенда, тестов и генераторов.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** (переключатель справа сверху).
4. **Загрузить распакованное расширение** → выберите распакованную папку.

Чтобы поставить из исходников, склонируйте репозиторий и укажите папку
`extension` (именно её, не корень репозитория).

Нужен Chrome 119 или новее.

> **Язык интерфейса берётся из браузера.** Chrome на русском — русская панель и
> русский отчёт; любой другой язык — английский. Оба перевода растут из одного
> источника, `tools/messages.mjs`, где языки стоят рядом строкой, и CI роняет сборку,
> если сгенерированные `_locales` с ним разошлись. Документы основания и комментарии
> в коде — на русском. Английский README — [README.md](README.md).

## Как снять сеанс

1. Откройте сайт, который хотите просветить.
2. Нажмите значок расширения — справа откроется панель.
3. **Записать этот сайт**. Chrome спросит разрешение на доступ к этому сайту:
   прибор работает только там, где вы его включили.
4. Вкладка перезагрузится. Так и должно быть: обёртки обязаны встать до первого
   скрипта страницы, иначе первый же вызов пройдёт мимо.
5. Походите по сайту. Панель обновляется на ходу.
6. **Сохранить отчёт** — текст для чтения, **Сохранить JSON** — полные данные.

Галочка «включая сторонние фреймы» расширяет наблюдение на встроенные фреймы с
чужих доменов. Без неё виден только сам сайт.

Галочка «экспорт без редакции» выключает вырезание значений. По умолчанию
идентификаторы, хеши почты и телефона в экспорт **не попадают** — отчёт можно
показать кому угодно. Снимать её стоит, только если вы понимаете, что делаете.

## Как проверить это самому

Прибор для недоверчивых людей должен быть проверяемым. Все утверждения выше
проверяются за пару минут, без доверия к автору.

**«Не отправляет никуда ни байта»:**

```bash
grep -rn "fetch(\|XMLHttpRequest\|sendBeacon\|WebSocket\|EventSource" extension --include=*.js
```

Единственный `fetch` во всём расширении — в `background/parsers/index.js`, и он
читает `chrome-extension://…` — собственные файлы деклараций. В
`instrument/main.js` эти имена встречаются только как **обёртываемые**, то есть
прибор их подменяет, а не вызывает.

**«Не исполняет удалённого кода»:** разборщики форматов — обычные JSON-файлы в
`extension/background/parsers/`. Это данные, а не код; движок их проверяет и
отвергает неправильные. См. [docs/05-parsers.md](docs/05-parsers.md).

**«Ничего не хранит на диске»:** журнал живёт в `chrome.storage.session` и
исчезает вместе с браузером. На диск (`storage.local`) пишется ровно одно
значение — положение галочки «включая сторонние фреймы»:

```bash
grep -rn "storage.local\|storage.sync" extension --include=*.js
```

**«Числа в документах не выдуманы»:** есть стенд с 28 сценариями съёма отпечатка
и отправки маячков, включая намеренный обход прибора. Он написан **раньше**
расширения и служит оракулом.

```bash
node bench/server.js
```

Открывать http://localhost:8080 — стенд тоже следует за языком браузера.
Полный прогон даёт ровно 10 сетевых обращений:
7 атрибутируемых, 3 обхода, 0 ложных срабатываний на 34 шумовых запросах.
Подробности — [bench/README.md](bench/README.md).

**Тесты:**

```bash
node tests/run.mjs
```

271 проверок в восьми наборах, без единой зависимости — только `node`. Самый
важный набор не тот, что проверяет разбор, а `tests/facts.test.mjs`: уберите
событие — исчезнет факт. Прибор не имеет права утверждать то, чего не записал.

## Пределы

Прибор честно перечисляет, чего он не видит и где его обманывают. Коротко:

- **Воркеры не наблюдаются.** Отпечаток, снятый внутри Web Worker, прибору не
  виден. Это единственный обход, который на практике сработал.
- **Страница видит обёртки.** Наблюдение изнутри помечено `internal`; до
  `confirmed` его поднимает только совпадение с сетью, которую страница
  подделать не может.
- **Другие расширения** в вашем браузере подменяют те же API. Их вызовы помечены
  «не сайт» — но отличить, действует расширение само или по просьбе страницы,
  прибор не может.
- **WebSocket сетью не проверяется:** разрешения не покрывают схему `ws`. Это не
  то же самое, что «запрос не ушёл».
- **Отпечаток шрифтов через `offsetWidth`** не покрыт намеренно: цена обёртки на
  таком горячем свойстве выше пользы.
- **Прибор стоит времени загрузки, и число нелестное.** Установка 73 обёрток на
  `document_start` занимает **6.4 мс** до того, как страница выполнит хоть
  строчку своего кода. На стенде — локальной странице с LCP в 60 мс — это дало
  **просадку LCP на 20%** (интервал 13–27%) при собственном пороге проекта в 5%.
  На живом сайте, где LCP измеряется секундами, те же 12 мс — меньше процента,
  но это ещё не замерено. Числа и метод —
  [bench/perf/README.md](bench/perf/README.md).

Полный список с объяснением каждого — [docs/06-limits.md](docs/06-limits.md).

## Устройство репозитория

```
extension/     само расширение (эту папку загружает Chrome)
  instrument/  обёртки, работают в мире страницы
  collector/   мост между миром страницы и расширением
  background/  service worker: журнал, сетевой тап, сверка, разбор, экспорт
    parsers/   декларации форматов — JSON, не код
  ui/          боковая панель
  icons/       значки, сгенерированы tools/icons.mjs
  _locales/    ru и en, сгенерированы tools/messages.mjs
bench/         стенд с намеренным фингерпринтингом, два origin
docs/          документы основания
tests/         тесты, запускаются голым node
tools/         генераторы: значки, файлы локалей, релизный zip
```
