Запись начинается с перезагрузки вкладки: обёртки должны стоять до первого скрипта страницы.

Что здесь наблюдается. Поверхности отпечатка и исходящее — из двух независимых источников: обёртки внутри страницы и сеть. Их несовпадение и есть детектор обхода.
Разбор формата подключён для GA4, Meta Pixel, Яндекс.Метрики и Вебвизора. Для остальных адресов тело показано как есть с подписью «формат не опознан» — это не то же самое, что «полей нет». Отпечаток шрифтов через offsetWidth не покрыт намеренно.

Пределы этой сборки
  • Наблюдение изнутри страницы помечено internal: канал виден странице. До confirmed его поднимает только совпадение с сетью, которую страница подделать не может.
  • Страница видит обёртки и канал доставки.
  • Воркеры не наблюдаются. Отпечаток, снятый внутри воркера, прибору не виден; заметен только маячок оттуда, и то по сети. Вызов из свежесозданного фрейма, наоборот, виден: прибор встаёт и туда тоже.
  • Другие расширения в вашем браузере подменяют те же API. Их вызовы помечены «не сайт». Отличить, действует расширение само или по просьбе страницы, прибор не может.
  • WebSocket сетью не проверяется: разрешения не покрывают схему ws. Это не то же самое, что «запрос не ушёл».
  • Разбор формата есть для GA4, Meta Pixel, Метрики и Вебвизора. Для остальных адресов подпись «формат не опознан» — это не «полей нет».
  • Не удалось разобрать стек — пишем «источник не определён», а не подставляем страницу.
